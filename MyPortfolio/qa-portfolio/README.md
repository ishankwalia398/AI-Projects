# Ishank Walia - QA Portfolio

A modern, professional portfolio website showcasing my 14+ years of Quality Engineering experience, AI-augmented testing expertise, and project work.

## 🚀 Features

- **Hero Section** with professional photo and key stats
- **Projects Showcase** featuring 30+ AI agents and automation tools
- **GitHub Integration** with live contribution calendar and stats
- **Experience Timeline** highlighting career achievements
- **Skills Matrix** covering DRM, Streaming, AI, and Automation
- **Contact Section** with all professional links
- **Fully Responsive** design for all devices
- **Dark Theme** optimized for developer portfolio

## 🛠️ Tech Stack

- **React** - UI library
- **Vite** - Build tool
- **React Icons** - Icon library
- **CSS3** - Custom styling with gradients and animations
- **Vercel** - Deployment platform

## 📦 Installation

```bash
npm install
```

## 🏃 Development

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) to view in browser.

## 🏗️ Build

```bash
npm run build
```

## 🚀 Deploy to Vercel

1. Install Vercel CLI:
```bash
npm i -g vercel
```

2. Deploy:
```bash
cd qa-portfolio
vercel
```

3. Follow prompts to link your project
