# AI Projects

A collection of AI, QA automation, agent, and career-tooling projects built while exploring practical applications of generative AI.

## Projects

- **Project 1 - Skills-based QA tooling**: Documentation, architecture, and tools for generating QA artifacts.
- **Project 2 - n8n Agents**: n8n workflows for QA assistance, content generation, and test-artifact creation.
- **Project 3 - AI Job Tracker**: Job-tracking prototype and test data.
- **Project 4 - Job Tracker**: Full-stack job-tracking application.
- **Project 5 - Global Career and Resume Suite**: Career and resume-focused web application.
- **Project 6 - Postman to Playwright**: API test migration and automation tooling.
- **Project 7 - LinkedIn Content Generator**: AI-assisted LinkedIn content creation application.
- **Project 8 - LangFlow Agents**: Agent flows for chat, bug triage, RCA, flaky-test analysis, and test planning.
- **Project 9 - RAG Experiments**: Retrieval-augmented generation experiments and QA assistants.
- **Project 10 - Portfolio Builder**: Portfolio-building project.
- **Project 12 - OTT DRM Troubleshooting Copilot**: AI-assisted troubleshooting for OTT and DRM workflows.
- **Project 13 - CrewAI Agent**: A simple CrewAI test-analyst agent.
- **Project 14 - CrewAI QA Pipeline**: A containerized CrewAI pipeline for QA workflows.
- **Project 15 - DeepEval Answer Relevancy Test**: DeepEval-based evaluation for measuring answer relevance in LLM responses.
- **MyPortfolio**: Portfolio content and the portfolio site.

## Reusable Skills

The [`Skills_Created`](Skills_Created/) directory contains reusable workflows for:

- Generating software test plans and backend test cases
- Converting Postman collections to Playwright tests
- Creating test cases in Jira and PractiTest formats
- Uploading test cases to PractiTest
- Validating nPVR and EPG data
- Analyzing nightly automated test reports

## Getting Started

Each project is self-contained. Open the relevant project directory and follow its README or package configuration for setup and run instructions. JavaScript projects generally use `npm install` followed by the scripts defined in `package.json`; Python projects document their dependencies in `requirements.txt` or `pyproject.toml`.
